数据导出 / 导入

导出当前所有数据为 JSON 文件，可在其他设备上导入恢复。导入时会覆盖本地数据。

⚠️ 危险操作

清除所有上传的数据、人员名单和历史记录。此操作不可恢复！

实时同步设置（Supabase）

配置后会自动接入云端：管理员上传任意文件即同步到 Supabase，所有成员打开页面自动拉取最新数据，无需再手动重新上传。

选择要同步的表格

只同步勾选的表格，未勾选的不会上传也不会自动同步。默认全选。修改后点上方「保存配置并同步」生效。

准备同步...

首次使用：① 在 Supabase 后台 SQL Editor 执行 supabase_schema.sql 建表（含大文件分片表）；② 把 Project URL 和 anon key 填上方保存；③ 点"一键同步到云端"把当前数据上传即可。大文件会自动拆分上传，避免超时。
